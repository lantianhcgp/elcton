SDK Privacy and Security Statement

In the SDK Privacy and Security Statement (hereinafter referred to as this "Statement"), Huawei Software Technologies Co., Ltd. (hereinafter referred to as "Huawei", "we", "us", or "our") clarifies privacy- and security-related information about the Wear Engine SDK to developers and their users (end users), including the processing of personal data, purpose of processing, permission usage, and how to obtain the latest version of the Wear Engine SDK. For details about the rights of end users (data subjects) and how other HMS Core services collect and use personal data, please refer to the HMS Core Privacy Statement.

If you are a developer, make sure that before accessing and using the Wear Engine SDK and its services, your app provides end users with information about the SDK in its privacy policy. The SDK can only be accessed after obtaining end users' consent or other legal bases. When your app uses the Wear Engine SDK to subscribe to heart rate alerts and read sensor data from wearable devices, it may involve sensitive personal data processing. It is recommended that your app display a pop-up to obtain users' separate consent in this case.

If you are an end user and want to use an app that has integrated the Wear Engine SDK, first carefully read the app's privacy policy and use the app only after you fully understand and agree to the policy.

Personal Data Processing

The Wear Engine SDK is designed for developers of apps and services running on phones and wearable devices.

By integrating the Wear Engine SDK, a developer's app or service on a phone can send messages, notifications, and data to a Huawei wearable device, as well as obtaining the status of the wearable device and reading sensor data. This also works the other way around, allowing an app or service on a Huawei wearable device to send messages and data to a phone.

To provide developers and end users with the SDK services, we will collect, use, and store necessary personal data as listed below.

The collected device information may vary depending on the device, OS, OS version, and permission that the developers determined when integrating and using the SDK. Therefore, developers shall notify end users of personal data that their apps collect.

Delayed SDK Initialization

The Wear Engine SDK may be initialized before the end user gives their consent to the app integrated with the SDK. To prevent this from happening, the SDK provides the requestPermission, which can be called to initialize the SDK only after the app has obtained the end user's consent.

Data Security

Connection involved in the SDK between the wearable device and the mobile phone requires two-way authentication when being established, to ensure that the device is trusted.

Data transmission processed by the SDK between the wearable device and the mobile phone is encrypted to prevent data leakage.

The SDK needs to authenticate the access API when accessing data. For example, the package name and signature need to be verified when an app accesses data.

The SDK can access data only after it obtains the authorization from users.

The data collected by the SDK is accessed by your service based on service requirements and privacy protection is provided to meet local privacy and security requirements.

Version Updates

To provide developers with the latest and secure services, we will update the SDK from time to time. We strongly recommend developers to integrate and use the latest version of the SDK, which can be downloaded by clicking here.

How Does the SDK Work

The Wear Engine SDK is loaded into your app during app packaging. It works when the app is started and runs in the app's process tasks, and stops as soon as the app is closed, without performing any additional operations in the background.
