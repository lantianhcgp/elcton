    A message is displayed indicating that HMS Core needs to be installed or updated when opening an app on a non-huawei phone 

Problem

When you run a Huawei-developed app (such as HUAWEI Health) on a non-huawei phone, a message is displayed indicating that HMS Core needs to be installed or updated.

When you run certain apps or games downloaded from HUAWEI AppGallery, a message is displayed indicating that HMS Core needs to be installed or updated.

When you open certain apps or games cloned from a Huawei phone on a non-huawei phone, a message is displayed indicating that HMS Core needs to be installed or updated.

Cause

Huawei-developed apps (such as HUAWEI Health) and certain apps or games downloaded from HUAWEI AppGallery or cloned from a Huawei phone have integrated with Huawei ecosystem capabilities and require support from the basic services provided by HMS Core, such as HUAWEI ID, game, and health services. If HMS Core is not installed on a non-huawei phone or the HMS Core version is outdated, these basic services cannot be used. The system will prompt you to install or update HMS Core to ensure that these apps or games can run properly.

Solution

Install or update HMS Core when prompted.

If you have installed HUAWEI AppGallery, the system will automatically direct you to the HMS Core details page in AppGallery. Touch Install or Update. If the system does not direct you to the page, open AppGallery, search for "HMS Core", and touch Install or Update.

If you have not installed HUAWEI AppGallery and cannot find it in the app store provided with your phone, you may use a browser to visit the official HUAWEI AppGallery website and search for and install HUAWEI AppGallery. Then open Huawei AppGallery, search for "HMS Core", and touch Install or Update.

After HMS Core is successfully installed, open the app or game in question again and log in to your HUAWEI ID.

HUAWEI AppGallery applies a strict app release procedure that involves a variety of security checks, including malware detection, security vulnerability scanning, privacy leakage checks, and manual real-name re-verification. You can be rest assured about downloading HMS Core from HUAWEI AppGallery as it has passed the security check.
