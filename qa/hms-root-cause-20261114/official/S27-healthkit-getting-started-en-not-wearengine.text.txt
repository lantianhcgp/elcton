Getting Started

Development Process

Follow the steps in the following process when you develop an app.

No.
  
Step
  
Description

1
  
Prepare for integration

Apply for the HUAWEI ID service: Health Service Kit uses the HUAWEI ID service and therefore, you need to apply for the HUAWEI ID service first.

Apply for Health Service Kit: Apply for the data read and write scopes for your app.

2
  
Prepare for development
  
Integrate the HMS Core SDK: Integrate the SDK of the Health Service Kit basic capability service into your development environment locally or remotely.

Configure the obfuscation scripts: Before building the APK, configure the obfuscation configuration file to prevent the HMS Core SDK from being obfuscated.

Import the certificate fingerprint, change the package name, and configure the JDK build version: Import the Keystore file to the app project. If the app package name is different from the package name used for applying the HUAWEI ID service, change the package name and configure the JDK build version.

3
  
Develop your app
  
Integrate the basic capabilities that Health Service Kit provides to develop related app features in Android Studio following the instructions in this guide.

4
  
Apply for verification
  
After the app development is complete, submit an application for verification to obtain the formal scopes of Health Service Kit.

5
  
Release your app
  
Perform pre-release check: Use the check tool to perform a self-check on the app, and perform a pre-release check against the Pre-release Checklist.

Submit the app for release review, a process that usually takes 1 to 2 workdays.

Development Environment

Android Studio 3.6.1 or later

JDK 1.8 or later

SDK and Gradle:
 
minSdkVersion 23

targetSdkVersion: 33 (recommended)

compileSdkVersion: 33 (recommended)

Gradle 5.4.1 or later

Test device:
 
A mobile phone running HarmonyOS or from Android 7.0 to Android 16 (API level from 24 to 36)

HMS Core (APK) 4.0.2.300 or later has been installed on the phone. To read data from the Huawei Health app, HMS Core (APK) 5.0.4.300 or later should be installed.

Huawei Health app 11.0.0.512 or later has been installed on the phone.
